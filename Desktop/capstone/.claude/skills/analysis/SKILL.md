# Analysis Skill

## When to use this skill
Use this skill whenever the task involves examining data, text, or documents 
to extract meaning — not just summarizing, but identifying patterns, themes, 
sentiment, or actionable insights.

## Steps to follow
1. Identify what kind of data you're analyzing (structured/unstructured, 
   text/numeric)
2. Determine the specific type of analysis needed (sentiment, thematic, 
   statistical, comparative)
3. Extract the relevant metrics, themes, or patterns systematically
4. Quantify findings where possible (percentages, counts, frequencies) 
   rather than vague language
5. Present findings in a clear, structured format (bullet points or a table)
6. Flag any assumptions made or limitations in the data

## Example
**Input:** "Analyze this customer feedback for common complaints"
**Output:** A categorized list of complaint themes with frequency counts, 
e.g. "Shipping delays (12 mentions, 40%), Product quality (8 mentions, 27%)..."

## Best practices
- Always state assumptions explicitly if the data is ambiguous
- Prefer numbers over vague descriptors ("high," "significant") 
- Never fabricate statistics not supported by the actual data
